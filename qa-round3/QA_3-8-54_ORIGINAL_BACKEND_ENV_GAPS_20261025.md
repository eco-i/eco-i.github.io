## 2. 다음 기술 검증의 필수 선행 순서

1. **비민감 원본동등 DDL 출처 승인:** 기존 카탈로그 메타데이터/18건 마이그레이션/공개 증분 SQL과 원본 서버 함수 정본의 누락 부분 확인. 원본 직원 row, PIN, 세션 토큰, 지문 사진, 백업 payload 복제 금지. 원본 서버 스키마 추출은 사용자가 동의한 정상 읽기 전용 경로에서만 별도로 계획.
2. **재현 가능한 오프라인 DB 우선:** PostgreSQL·함수 보안 속성·RLS·owner·GRANT/REVOKE·트리거·공유 revision 테스트. 정식 실행 가능한 새 QA 초기 스키마가 아직 없으므로 과거 운영 SQL 18개를 비검증 방식으로 그대로 replay해서 실운영 동등하다고 하지 않는다.
3. **독립 QA 웹/API:** 새 비운영 QA 프로젝트 비용·권한을 확인하고 사용자 승인을 받은 뒤에만 생성. 브라우저는 QA URL/검증된 publishable key만 허용, 운영 호스트 요청 **0건**·네트워크 차단 점검.
4. **P0 종단 시험:** 별도 관리자 A/B 및 일반·조회전용·비활성 가상 직원, 입출퇴근/인사/휴일근무/휴무/메모/사진 합성 데이터. PIN 강제·권한박탈·토큰 만료·동시 CAS·기존 writer fallback·오류/성공 지연 응답 각각 실행; SQL 전후 snapshot, HTTP 상태, 브라우저 화면을 함께 수집.
5. **공식 블록 게이트:** 위 시험이 원본동등 조건을 충족해 검수 기준을 재확인한 시점부터만 **3-8-54 착수**. 현재 28/28 및 기존 21/21·24/24 scoped PASS는 완료 블록을 늘리거나 전체 CLEAN을 뜻하지 않는다.

## 5. 2026-10-25 후속 읽기 전용 운영 카탈로그 재검증 — *이번 턴에 실제 추가된 증거*

**주의:** 문서 서두의 "운영 Supabase 접속/쿼리 없음"은 **그 문서를 처음 작성했던 시점**을 설명한다. 다음은 2026-10-25 후속 회차에서 별도로 수행한 실제 읽기 전용 메타데이터 조회다. 과거 조사 시점과 혼동하지 않는다.

- 계정의 프로젝트 목록 조회 결과, **현재 두 개의 기존 이용 프로젝트만 확인**되며 **근무모아 독립 QA 전용 Supabase 프로젝트는 없음**. 다른 서비스 DB를 QA로 재활용하지 않는다. 금액이 나올 수 있는 프로젝트/브랜치 생성은 요청/실행하지 않음.
- 운영 Supabase 연결의 **읽기 전용 `list_tables(verbose=true, schemas=['public','workmoa_guard'])`** 메타데이터 조회 2회. SQL 원문을 제출하거나 `execute_sql`·마이그레이션·RPC 실행·실제 행 SELECT·운영 설정 변경을 전혀 하지 않았다.
- **현재 구조 목록:** 테이블 **28/28**, 컬럼 **190/190**, 과거 비공개 카탈로그와 테이블명·컬럼명 전부 일치. `text[]` 두 건이 일반 `array` 타입 설명으로 표시되는 API 표기 차이 외에 확인된 컬럼 구조 변화 없음.
- **새로 확보 가능한 범위를 확인한 자료:** 72개 컬럼의 기본값 정의 메타데이터가 API에 있음(이전 비공개 파일은 기본값 MD5만 보유), 기본키가 존재하는 테이블 **28개 / 기본키 컬럼 합계 31개**, 외래키 관계 메타데이터 **55건**, RLS 활성 테이블 **27개**. RLS 미활성 1개는 기존의 **비공개 내부 보조 스키마** 테이블로 과거 카탈로그의 상태와 같아 새 보안 악화 증거가 아님.
- 기존 비공개 ACL 해시 기록의 RLS enabled/disabled 분포와 **28/28 일치**(변경 0). 기록에 인덱스 **52**, 제약조건 **108**, 트리거 **15**, 정책 **1**, 함수 ACL **214** 구조 기록 존재하나, **각 CREATE/정책 원문을 이 API가 내보내는 것은 아니다**.
- 이 실행의 응답에는 행 수 추정 메타데이터가 포함될 수 있으나, 실제 직원/세션 행이나 PIN/지문을 조회·다운로드하지 않았고 **행 개수도 보고서에 수록하지 않는다**. 원본 컬럼 목록, 기본값 문자열, private catalog JSON을 공개 저장소·Actions 파일·CI 아티팩트로 복사하지 않았다.

**판정 변경:** 28테이블/190컬럼 자체가 없는 것이 아니라, **현재 읽기 전용 경로에서 타입·기본값·PK·FK·RLS enabled 등의 재구성 단서는 확인됨**. 남은 최상위 장애는 **원본 함수 구현과 보안 규칙/제약/트리거 원문 및 기존 호출 이행 조건을 안전한 비공개 경로로 확보하고, 운영 외부 격리 QA 서버에서 등가 실행을 검증하는 것**이다. 제한된 초기 증분 migration만으로 전체 원본 DDL/서버 등가성을 가정할 수 없다.

**추가 안전 검사 관련:** 이전 GitHub용 합성 교차 잠금 SQL 파일 생성은 자동 안전 검사에서 차단됨. 이를 CI/CLI/SQL Editor/새 도구를 통한 동일 요청 우회 대상으로 삼지 않는다. 고객센터 답변 전 복구 금지인 데이터관리 RPC 3종도 계속 보류.
