- 분류: LOW, 모바일·키보드 접근성/사용성. 데이터 저장·직원 기록 변경은 없음.
- QA 원본 index.html blob: `778529b59b550ee1f3bf4e8e3b0ea27463427276`.
- QA 수정 blob: `ce076c820937c62bf6b2a2d1f471f9fbf0fe0ce6`, 수정 커밋 `49ba06da4dfdf9526ecf5e21adbf1beea33467d5`.

## 재현
1. 근태 기간 선택기에서 날짜 버튼에 키보드 포커스를 두고 시작일을 선택.
2. 원본 `chooseAttendanceDate`가 endDate 모드로 전환한 뒤 `renderAttendanceDatePicker()` 호출.
3. 원본 render 함수의 `datePickerGrid.innerHTML=html`이 포커스된 버튼을 DOM에서 제거해 포커스가 BODY로 돌아감. 팝업은 여전히 열려 있음.
4. 원본 GitHub 함수 기반 가짜 DOM 재현과 별도 headless Chromium(390x844) `innerHTML` 최소 재현에서 확인. 후자는 전체 앱 E2E가 아닌 독립 브라우저 재현.

## QA 전용 수정
- 재렌더 직전 해당 그리드 내부의 포커스된 날짜 키를 저장.
- 재렌더 후 팝업이 열린 경우 같은 날짜 버튼을 찾고, 그 날짜를 선택할 수 없으면 다음 가능한 날짜·마지막 가능한 날짜·월 이동 버튼 순서로 `focus({preventScroll:true})`.
- 날짜 값, 이벤트, 저장 RPC, 휴근·연차 로직, DOM ID 및 CSS는 변경하지 않음. 코드 633자 순증.
- `main` 및 실제 직원 DB 무변경.
