## 독립 재현
실제 QA 브랜치 JS를 V8 격리 하네스에 넣고, 관리자 유효 세션/지연된 저장 RPC를 모의한다.
1. 2026-12-01 A조 수동 편성을 `주`로 수정한 상태에서 저장 시작.
2. 서버 RPC 응답을 보류하는 동안 같은 셀을 `야`로 변경.
3. 서버가 처음 요청된 `주` 상태로 저장 성공 응답.
4. 기존 JS는 성공 응답을 적용하면서 편집 중 표시되던 `야`를 `주`로 되돌리고 성공 토스트를 표시한다.
5. 사용자가 저장 도중 추가로 변경한 값이 안내 없이 유실되는 현상 **확인**.

- 관리자의 고정 입력 13개와 동적 조작 컨트롤 6개를 저장 중 비활성화하고 종료 후 복구.
- 저장 중 메시지를 표시하며 저장 실패 메시지(이전 3-8-5-002 QA 수정)를 보존.
