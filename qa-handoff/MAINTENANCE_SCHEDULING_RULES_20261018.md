# 근무모아 정비기간 근무편성 규칙 (사용자 확인 기준, 2026-10-18)

이 문서는 앞으로 구현할 **관리자 전용 정비기간 설정·조별 수동 편성**의 공식 요구사항이다. 2026-10-18 현재 기능 구현/배포를 뜻하지 않는다.

## 연중 근무 기본원칙
- A/B/C/D 4조는 지정 앵커를 기준으로 8일 주기 주주휴휴야야비비를 날짜별로 계속 진행한다. 정비가 발생해도 패턴 인덱스를 중단하거나 재시작하지 않는다.
- 직원이 소속 조를 옮겼다면 인사배치 효력 시작일부터 새 소속조 패턴이 적용된다.
- 상반기 보통 4월, 하반기 보통 11월 정비. 정확한 시작/종료는 확정 후 관리자가 별도로 입력한다. 날짜를 예측해 임의로 적용하지 않는다.

## 정비기간 일근 및 휴무
- 정비기간 중 일반 업무일에 교대조 직원의 실제 근무는 09:00~18:00 일근(기존 화면 표기 '주2')이다.
- 토요일·일요일·법정공휴일·대체공휴일·정부가 임시로 지정한 공휴일에는 일근을 쉬며, 회사 지정 **공단 창립기념일(매년 2월 12일)**에도 휴무. 공단 창립기념일이 주말과 겹쳐도 별도 대체휴일은 없다.
- **정비 시작 직전** 전날 주2를 마쳤으면 첫 이틀 휴무 보장; 전날 주1만 수행했으면 추가 휴무 없이 정비 첫날부터 일근.
- 전날 야2를 마쳤으면 첫 이틀 휴무 보장; 전날 야1만 수행했으면 첫날은 아침 퇴근 후 하루 쉬고 둘째 날부터 일근(사용자 확인).
- 정비기간 종료 이후에는 추가 휴무 보장 없이 해당 날짜 원래 교대주기대로 근무.
- 정비기간 **마지막 날부터** 원래 교대주기상 야간근무인 조는 실제 야간근무를 한다. 같은 날 해당 조는 09:00~18:00 주간 일근을 하지 않는다. 이는 마지막 날의 야1/야2 원래 주기 중 해당 야간인 경우 모두 판단해야 하며 상세 전환 로직을 회귀 검수한다.
- 앞뒤 공휴일/주말과 휴무 보장이 겹칠 경우 계산 규칙은 실제 현장 편성표와 대조하여 정한다. 규칙에서 자동 편성한 결과는 확정 전 관리자 미리보기가 필요하다.

## 후속 관리자 기능 요구사항
- 관리자 전용 정비기간 등록/변경/취소. 기간 시작·종료일/사유 관리, 직원 모두 읽기, 서버측 관리자 권한 검증 및 감사로그.
- 자동 4조 근무표 미리보기 + 관리자가 **조별·날짜별 근무표를 개별 수정** 가능. 수동 편성 우선순위가 기본주기/정비 자동 편성보다 높으며, 저장 후 모든 직원에게 동일하게 표시. 원래 기본 8일 주기는 수정하지 않는다.
- 편성이 달라지면 내/전체 근무표, 가용인원, 연차 실근무시간, 지문 근무일, 휴근·대휴, 월간 야간 횟수 및 초과근무 가능시간에 일관되게 반영한다.
- 월 초과근무 가능시간은 실제 야간근무 횟수 0~8회별 회사 기존 기준(0:23시간,1:20시간,2:17시간,3:15시간,4:12시간,5:10시간,6:8시간,7:6시간,8:3시간)대로 계산한다. 소속조/직원범주는 정비 중에도 그대로 유지한다.
- 임시공휴일은 날짜 확정 후 정확히 관리/등록할 수 있도록 추가 검토가 필요하다. 기존 HOLIDAYS 상수만으로는 나중에 정부 지정한 임시공휴일을 자동 갱신할 수 없다.
- 확정된 과거 기록·직원별 근태·지문 사진·초과근무 계획/완료·연차 정보는 일괄 재작성하지 않는다. 편성 수정/삭제 시 영향 범위와 충돌 경고, 감사 이력과 회귀시험 필요.

## 가정 및 사례
- 2027-04-14 정비 시작, 2027-04-21 정비 마지막 날은 **설명용 가상 날짜**이며 실제 정비 확정일이 아니다.
- 시작 직전 04/12 주1 + 04/13 주2 -> 04/14,04/15 휴; 04/13 주1 -> 04/14부터 일근.
- 04/12 야1 + 04/13 야2 -> 04/14,04/15 휴; 04/13 야1 -> 04/14 귀가 후 휴, 04/15부터 일근.
- 04/21 종료일이 원래 야간주기에 해당하는 조는 그날 야간 출근, 주간 일근 제외.
- 2026-10-01~15 기존 편성은 코드 내 별도 예외로 유지 중; 관리자 기능을 구현할 때 기존 운영 기록과 대조해 보존할 것.
