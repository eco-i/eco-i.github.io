# 근무모아 기존 공휴일 근무일 변경·복원 구현 / 검수 기록 (2026-10-18)

## 목적과 범위
- 운영 기준: ver20261018-2256 → **ver20261018-2313**.
- 관리자가 기존 2026~2027 HOLIDAYS 및 2028~2035 FUTURE_HOLIDAYS에 있는 **개별 날짜**를 근무일로 변경하거나 공휴일로 복원.
- 원본 공휴일 정의(정적 JS, future_holiday_calendar) 자체를 수정/삭제하지 않음.
- 관리자 정비기간 관리의 **⑤ 기존 공휴일 변경·복원** UI 제공.
- 저장은 기존 관리자 RPC `admin_save_maintenance_schedule`의 revision CAS, 행잠금, 세션/권한 검증, 감사 로그 및 Realtime 알림을 유지.
- 모든 직원의 달력·일근 휴무·대정비 자동편성·연차 근무시간·휴일근무 대상 판정이 동일한 저장 상태를 사용.
- 토요일/일요일은 원래 주말 휴무 그대로, 회사 고유 2월 12일 창립기념일은 변경 금지.
- 2026-10-01~2026-10-15 기존 특별 편성에 속한 날짜는 변경 금지.
- 과거 날짜 변경 시 확인 경고, 기존 근태 원본 직접 UPDATE/DELETE 없음.

## 변경 파일

- `maintenance-20261018.js` (excludedHolidays 배열, 검증·미리보기·저장·복원·구버전 읽기 호환)

## 중요 주의
- 일별 예외 기능이며, 법령 변경에 따른 특정 공휴일의 여러 해 전체 일괄 삭제는 지원하지 않음.
- 주말과 겹친 지정 공휴일을 근무일로 바꾸더라도 토·일요일 자체는 휴무이므로 근무일로 전환되지 않음.
- 사용자 실제 관리자 휴대폰·PC 저장 및 직원 단말 화면 반영은 별도 실기기 확인 필요.
- 새로운 정부 공휴일 고시는 자동 반영되지 않으며 관리자가 판단하여 적용.
