# 근무모아 — 2차 브라우저 종합검수 종료 이후 운영 반영 전 체크리스트

이 체크리스트는 2-8-290 종료심사와 **별도의 운영 반영 승인**을 위한 것이다. 2차 자동화·Chromium/모의 RPC 검수를 마치더라도 이 항목을 수행하지 않은 상태로 실제 운영 배포를 승인하지 않는다.

## 실제 서버와 계정 — 필수
- [ ] 권한이 다른 테스트용 두 계정(관리자, 일반 직원)으로 실제 Supabase Auth 세션을 생성한다.
- [ ] RLS에서 다른 직원의 지문 사진, 근태/연가/인사 자료 목록·상세·수정·삭제가 실제로 차단되는지 검증한다.
- [ ] 실제 계정으로 새 업로드 및 문서 읽기, 세션 만료/토큰 갱신/권한 변경을 검증한다.
- [ ] 탭 간 로그아웃과 복원 미리보기·업로드 간 경합, 폐기 토큰 재사용 차단을 검증한다. 외부에서 raw `localStorage` SESSION_KEY를 임의 삭제하는 비표준 경로는 별도 위험으로 관리한다.

## 실물 모바일 — 필수
- [ ] Android Chrome 및 조직에서 지원하는 Android 브라우저에서 **카메라/내 파일** 각 선택을 검증한다.
- [ ] iOS Safari에서 카메라/내 파일 선택, 정상 업로드, 취소, 재선택, 큰 이미지, 권한 거부를 검증한다.
- [ ] 실제 통신 중단·통신 재개·백그라운드 전환·BFCache 복귀·로그인 상태 유지 및 잔상/개인정보 노출을 확인한다.
- [ ] 실제 저사양 기기에서 업로드·이미지 압축·메모리·뒤로가기·화면 축소/확대를 확인한다.

## 복구와 운영 — 필수
- [ ] staging/격리 DB에서만 백업/복원 내보내기→미리보기→복원→재백업 동등성을 검증한다.
- [ ] 운영 DB에 실제 삭제/파괴적 복원을 수행하지 않는다.
- [ ] 장애 복구/롤백 절차와 복원 전 스냅샷 및 권한·개인정보 보관 설정을 승인받는다.
- [ ] 운영 공개 이전에 위 항목의 실제 담당자, 실행 날짜, 증거, 장애시 조치 및 최종 승인자를 기록한다.

## 종료심사와의 관계
- `2-8-290 AUTOMATED_QA_EXIT=APPROVED` 조건을 만족하면 **자동화·브라우저 검증 범위의 2차 종합검수만 종료**할 수 있다.
- 본 문서 항목들이 체크되지 않았으면 `PRODUCTION_RELEASE=NOT_APPROVED_PENDING_REAL_WORLD_SMOKE` 유지.
- 위 항목에서 실제 제품 결함이 재현되면 신규 위험/결함을 기록하고 대상 기능만 수정·재검증한다. 이미 검증한 31연속 CLEAN 기록을 근거 없이 소급 무효로 만들거나 무한 블록 반복을 재개하지 않는다.
